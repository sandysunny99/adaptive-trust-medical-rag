# Research Gaps — Remaining

**Date:** 2026-08-30  
**Commit:** 4a704f5  

---

## Engineering Gaps

| Gap | Severity | Description |
|---|---|---|
| Real LLM backend | CRITICAL | LiveModelAdapter generates template strings. No real language model is called anywhere in the system. |
| Semantic embedding model | HIGH | SimpleEmbeddingModel uses 7 hardcoded words. Dense retrieval results are not semantically meaningful. |
| Variant B/C confound | HIGH | Variants B and C call identical retriever code with same corpus. Experimental isolation is broken. |
| Evidence corpus size | HIGH | 4-18 documents. Meaningful evaluation requires 100+ pharmacological evidence chunks. |
| Live database | MEDIUM | PostgreSQL/pgvector not connected in any experiment. All retrieval is pure-Python in-memory. |
| Trust metadata reporting bug | MEDIUM | Ablation logs report hardcoded weights inconsistent with trust.yaml. |
