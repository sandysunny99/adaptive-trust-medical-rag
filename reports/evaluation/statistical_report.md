# Statistical Research Report (Summary)

- **Pairwise Statistical Tests:** Welch t-test (two-tailed, normal approximation).
- **Effect Sizes:** Cohen's d unsigned magnitude.
- **Confidence Intervals:** 95% bootstrap CIs (N=1000 resamples, fixed seed 42).
