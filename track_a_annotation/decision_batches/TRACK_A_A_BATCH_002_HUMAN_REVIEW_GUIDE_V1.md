# TRACK_A_A_BATCH_002_HUMAN_REVIEW_GUIDE_V1

## REVIEW PROCEDURE

1. Read the query.
2. Identify exactly what information the query requests.
3. Read the retrieved evidence.
4. Determine whether the evidence substantively addresses the requested information.
5. Distinguish direct evidence from merely related information.
6. Consider whether important information is missing.
7. Note genuine ambiguity.
8. Select the final schema label yourself.
9. Select the final schema grade yourself.
10. Provide the supporting evidence span yourself.
